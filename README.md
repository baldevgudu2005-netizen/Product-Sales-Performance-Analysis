# Product Sales & Performance Analysis

## Project Overview

This project presents an interactive Power BI dashboard developed to analyze product sales, profitability, customer segments, and regional performance.

The dashboard uses data visualization techniques and DAX measures to transform raw sales data into meaningful business insights. It helps users understand sales trends, compare product performance, and evaluate profitability.

## Objectives

- Analyze overall sales and profit performance.
- Compare sales and profit across product categories.
- Identify top-performing products.
- Analyze monthly sales and profit trends.
- Understand customer segment distribution.
- Visualize sales performance across different states and regions.

## Tools & Technologies

- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- CSV Dataset
- Data Visualization
- Data Analysis

## Key Performance Indicators (KPIs)

1. Total Sales
2. Total Profit
3. Total Orders
4. Profit Margin

## Dashboard Visualizations

The dashboard contains five major visualizations:

| Visualization | Purpose |
|---|---|
| Sales & Profit Comparison by Category | Compares sales and profit across categories |
| Monthly Sales & Profit Trends | Shows sales and profit trends over time |
| Top 10 Products – Sales vs Profit | Identifies and compares top-performing products |
| Sales Distribution by Customer Segment | Displays sales distribution across customer segments |
| Sales Performance by State & Region | Visualizes geographical sales performance |

## Interactive Features

The dashboard includes interactive slicers for:

- Year
- Category
- Region

These filters allow users to explore the data dynamically and view insights based on their selections.

## DAX Measures

The project uses DAX measures to calculate important business metrics, including:

- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Total Customers
- Total Products
- Profit Margin
- Average Order Value

## Dataset

The project uses a CSV-based sales dataset containing product, category, customer, order, sales, profit, and geographical information.

## Project Files

- `Product_Sales_Performance.pbix` – Power BI dashboard file.
- `Sample_Superstore.csv` – Dataset used for analysis.
- `README.md` – Project documentation.

## How to Use

1. Download or clone this repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. Explore the dashboard visualizations.
4. Use the interactive slicers to filter the data by year, category, and region.

## Project Outcome

This project demonstrates the practical application of Power BI, DAX calculations, and interactive data visualization for business intelligence and sales performance analysis.
